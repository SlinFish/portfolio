FEATURED PROJECT

CUSTOM MOBILE SOFTWARE • ACTIVE DEVELOPMENT

EasyGetApp

A multi-service mobile platform being developed for Android and iOS using Kotlin Multiplatform and Compose Multiplatform. The current strongest part of the project is the ride-dispatching system.

Current focus Ride / Taxi Dispatcher

The customer-side ride experience is substantially implemented, while the driver-side experience is actively being completed. Other EasyGet services are planned for future development and are not presented as finished features.

What I have built

  • Shared Android and iOS application architecture with Kotlin Multiplatform.
  • Taxi dispatch functionality with maps, location, driver matching, distance and ETA calculations.
  • Customer ride flow including destination selection, ride selection, booking and driver acceptance.
  • Driver-side workflows for availability and ride requests.
  • Backend services using Node.js, REST APIs and Firebase Cloud Functions.
  • Firebase Authentication and Realtime Database integration.
  • Agora integration for real-time communication between drivers and clients.
  • Stripe payment gateway integration.
  • Backend deployment to Railway.
  • iOS target integration using Xcode and Swift.
